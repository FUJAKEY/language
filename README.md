# MoyLang

MoyLang — экспериментальный язык программирования с собственным синтаксисом. Для него разработаны два варианта реализации:

1. Минимальный интерпретатор на C++.
2. Простейший компилятор, который генерирует x86-64 машинный код через ассемблер.

## Синтаксис

- `var <имя> = <выражение>;` — объявление переменной (поддерживается только в интерпретаторе).
- `print(<выражение>);` — вывод значения на экран.
- `if (<условие>) { ... } else { ... }` — условный блок.
- `while (<условие>) { ... }` — цикл.
- Строки, начинающиеся с `#`, считаются комментариями.

Примеры программ располагаются в каталоге `examples/`.

## Сборка и запуск интерпретатора

1. Убедитесь, что установлен компилятор C++ (g++).
2. Скомпилируйте интерпретатор:
   ```bash
   g++ -std=c++17 -O2 cpp/moylang.cpp -o moylang
   ```
3. Запустите пример:
   ```bash
   ./moylang examples/hello.moy
   ```

## Сборка и использование компилятора

1. Скомпилируйте компилятор:
   ```bash
   g++ -std=c++17 -O2 cpp/moyc.cpp -o moyc
   ```
2. Скомпилируйте исходник MoyLang в ассемблер и соберите бинарник:
   ```bash
   ./moyc examples/hello2.moy hello2.s
   gcc -nostdlib -static hello2.s -o hello2
   ./hello2
   ```

Компилятор генерирует ассемблер, который напрямую использует системные вызовы `write` и `exit`, поэтому полученный бинарный файл не зависит от других языков или библиотек.
