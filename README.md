# MoyLang

MoyLang — экспериментальный язык программирования с собственным синтаксисом. Реализован минимальный интерпретатор на C++, поэтому запуск не зависит от Python.

## Синтаксис

- `var <имя> = <выражение>;` — объявление переменной.
- `print(<выражение>);` — вывод значения на экран.
- `if (<условие>) { ... } else { ... }` — условный блок.
- `while (<условие>) { ... }` — цикл.
- Строки, начинающиеся с `#`, считаются комментариями.

Пример программы находится в каталоге `examples/hello.moy`.

## Установка и запуск

1. Убедитесь, что установлен компилятор C++ (g++).
2. Скомпилируйте интерпретатор:
   ```bash
   g++ -std=c++17 -O2 cpp/moylang.cpp -o moylang
   ```
3. Запустите пример:
   ```bash
   ./moylang examples/hello.moy
   ```

Интерпретатор не требует сторонних зависимостей и легко собирается в Termux и любой современной Linux-системе.
