# MoyLang

MoyLang — минималистичный интерпретируемый язык программирования, вдохновлённый Python. Его цель — предоставить максимально простой синтаксис и удобную установку в средах Termux и Linux.

## Синтаксис

- `let <имя> = <выражение>` — создание переменной.
- `print <выражение>` — вывод значения на экран.
- `input <имя> ["подсказка"]` — чтение строки от пользователя.
- `if <условие>` и `while <условие>` — управляющие конструкции. Блоки завершаются ключевым словом `end`.
- Любая строка, начинающаяся с `#`, считается комментарием.
- Неизвестные команды передаются как обычный код Python.

Пример программы находится в каталоге `mlang/examples/hello.ml`.

## Установка и запуск

1. Убедитесь, что установлен Python 3 (`python3 --version`).
2. Клонируйте репозиторий и перейдите в директорию проекта.
3. Запустите программу командой:
   ```bash
   python3 mlang/interpreter.py mlang/examples/hello.ml
   ```

Интерпретатор не требует сторонних зависимостей и работает «из коробки» в Termux и любой современной Linux-системе.
